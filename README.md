# CampusConnect – Placement & Intelligence Platform 🎓

CampusConnect is a placement and intelligence platform designed to help colleges, students, recruiters, and placement officers manage and understand campus placement activities through a centralized digital platform.

## 🚀 Overview

CampusConnect brings placement-related information into one platform and provides role-based access for different users involved in the campus recruitment process.

The platform focuses on placement intelligence, student and recruiter workflows, and analytics such as placement rates, department-wise CTC benchmarks, and company/partner rankings.

## ✨ Features

- 🎓 Student placement management
- 🏢 Recruiter-related workflows
- 👨‍💼 Placement Officer / Admin view
- 📊 Placement analytics and insights
- 💰 Department-wise CTC benchmarks
- 📈 Placement rate analysis
- 🏆 Partner/company rankings
- 🔄 Role-based navigation
- 🤖 AI-powered capabilities using Gemini API
- 📱 Interactive web-based interface

## 👥 User Roles

CampusConnect supports different user perspectives through role-based navigation:

- **Student** – Access placement-related information and opportunities
- **Recruiter** – Manage recruitment-related activities
- **Placement Officer / Admin** – Monitor placement activities and institutional insights
